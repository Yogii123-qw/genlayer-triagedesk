# Demo script (under 45 seconds)

Record this only after the Studio deploy is done and the frontend points at the deployed contract. The script below is a plan, not a recording.

1. Open the TriageDesk page. Show the empty leaderboard state, then connect a wallet. (0-8s)
2. Fill the submit form with a short reentrancy report and send it. Show the transaction confirm. (8-20s)
3. Click Run triage on the new report. Wait for the scores to land, then open the report detail and point at the four rubric bars with reasons. (20-35s)
4. Show the leaderboard with the report ranked by total score. End on the detail view. (35-44s)

Narration, one line: "TriageDesk takes a bug report, scores it on four rubrics with a language model, agrees on the scores through GenLayer validators, and ranks it on the leaderboard."
